# Sprint_9

Созданы автотесты для проверки функциональности сервиса https://foodgram-frontend-1.foodgram.education-services.ru/signin

В папке tests содержатся файлы с тестами, разделенные по страницам: 
- test_create_recept.py содержит тесты для проверки функциональности создания рецептов

- test_login.py содержит тесты для проверки функциональности входа в личный кабинет

- test_registration.py содержит тесты для проверки функционала регистрации пользователя



В папке locators содержатся файлы с локаторами, разделенными по страницам
В папке page_object содержатся файлы с методами, разделенными по страницам
В папке data содержатся вспомогательные данные
